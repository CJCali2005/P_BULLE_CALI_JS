Ce dépôt contient une série d'exercices progressifs permettant d'apprendre les bases de JavaScript moderne, l'utilisation des modules ESM, la création de fonctions réutilisables ainsi que les tests unitaires avec Jest.

## 🎯 Objectifs

- Apprendre les fondamentaux de JavaScript
- Manipuler les conditions et les boucles
- Créer et utiliser des fonctions
- Travailler avec les données
- Découvrir l'asynchrone
- Utiliser les modules ESM
- Valider son code grâce aux tests automatisés

## ⚡ Installation

```bash
git clone https://github.com/ton-pseudo/ton-repo.git

cd ton-repo

npm install
```

---

## 🧪 Lancer les tests

### Exécuter tous les tests

```bash
npm run test
```

### Exécuter une mission spécifique

```bash
npm run test -- exercices/axe-controle/portes-citadelle/
```
