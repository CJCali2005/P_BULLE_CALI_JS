# 🚀 Exercices JavaScript Moderne (ESM)

Projet réalisé dans le cadre de la formation informatique à l'ETML.

Ce dépôt contient une série d'exercices progressifs permettant d'apprendre les bases de JavaScript moderne, l'utilisation des modules ESM, la création de fonctions réutilisables ainsi que les tests unitaires avec Jest. Le but est de développer de bonnes pratiques de programmation tout en découvrant des outils utilisés dans le monde professionnel. 【1-33c50f】

---

## 🎯 Objectifs

- Apprendre les fondamentaux de JavaScript
- Manipuler les conditions et les boucles
- Créer et utiliser des fonctions
- Travailler avec les données et les chaînes de caractères
- Découvrir l'asynchrone
- Utiliser les modules ESM (`import` / `export`)
- Valider son code grâce aux tests automatisés Jest

## ⚡ Installation

### 1. Cloner le dépôt

```bash

```

```bash

```

```bash

```

## 🧪 Lancer les tests

### Tous les tests


## 💡 Organisation du travail

Pour chaque exercice :

1. Compléter la fonction demandée.
2. Ajouter la documentation JSDoc nécessaire.
3. Exécuter les tests.
4. Corriger les erreurs éventuelles.
5. Commit et push sur GitHub.
6. Passer à l'exercice suivant.
